## 1. Цель работы

## 2. Структура каталога `lab01`

- `specs/` — файлы описания пакетов:
  - `sample-streltsov.spec` — spec-файл пакета минимальной структуры («нулевой пакет»);
  - `streltsov-hello.spec` — spec-файл функционального пакета (сценарий приветствия).
- `sources/` — исходные файлы для сборки:
  - `streltsov-hello.sh` — исполняемый сценарий на командной оболочке.
- `env/` — зафиксированное состояние окружения:
  - `repos.txt` — список активных APT-репозиториев хост-системы;
  - `host-packages.txt` — полный перечень пакетов, установленных на хосте (2119 пакетов);
  - `chroot-packages.txt` — полный перечень пакетов изолированного сборочного окружения (182 пакета);
  - `hasher-config` — копия конфигурационного файла `~/.hasher/config`.
- `logs/` — журналы выполнения операций и анализа:
  - `zlib-info.log`, `zlib-files.log`, `zlib-requires.log`, `zlib-provides.log`, `zlib-whatrequires.log`, `zlib-whatprovides.log` — анализ базовой разделяемой библиотеки;
  - `zlib-devel-info.log`, `zlib-devel-files.log`, `zlib-devel-requires.log`, `zlib-devel-qf.log` — анализ парного пакета разработки;
  - `hasher-init.log`, `hasher-builder.log`, `hasher-rooter.log` — развёртывание и тестирование ролей в hasher;
  - `sample-streltsov-build.log` — сборка нулевого пакета;
  - `streltsov-hello-build.log` — сборка пакета с функциональностью;
  - `rebuild.log` — автоматическая сборка пакета утилитой `hsh`;
  - `rebuild-diff.log` — сопоставление контрольных сумм и состава файлов между ручной и автоматической сборкой;
  - `env-diff.log` — перечень пакетов, присутствующих на хосте, но отсутствующих в изолированном окружении.
- `check/` — средства автоматической приёмочной проверки:
  - `expected.txt` — эталонный вывод программы `streltsov-hello`;
  - `check-lab01.sh` — сценарий автоматизированного контроля выполнения заданий 1–8.

## 3. Классификация зависимостей (Задание 3)

В ходе исследования разделяемой библиотеки `zlib` и парного пакета `zlib-devel` составлена следующая классификация зависимостей:

| Класс зависимости | Пакет / Возможность | Обоснование отнесения |
|---|---|---|
| **Инструментальная** | `rpm-build` | Необходим для сборки пакетов из spec-файлов и архивов исходных кодов на хост-системе; не включается в состав готового пакета. |
| **Инструментальная** | `hasher` / `hasher-priv` | Инструмент создания безопасного изолированного сборочного контейнера без суперпользовательских привилегий на хосте. |
| **Сборочная (BuildRequires)** | `zlib-devel` | Содержит заголовочные файлы C (`zlib.h`, `zconf.h`) и символические ссылки на разделяемые библиотеки (`libz.so`), необходимые компилятору и линкеру при трансляции исходного кода. |
| **Сборочная (BuildRequires)** | `gcc`, `make` | Компилятор и система сборки, вызываемые на этапах `%build` для порождения машинного кода. |
| **Эксплуатационная (Requires)** | `zlib` (`libz.so.1`) | Предоставляет динамическую библиотеку алгоритмов сжатия `DEFLATE`, требуемую скомпонованному бинарному файлу во время его исполнения. |
| **Эксплуатационная (Requires)** | `/bin/sh` | Автоматически вычисленная зависимость пакета `streltsov-hello`, определяемая парсером find-requires по шебангу `#!/bin/sh` для обеспечения возможности исполнения скрипта. |

### Состав devel-пакета `zlib-devel`
- Заголовочные файлы: `/usr/include/zconf.h`, `/usr/include/zlib.h`
- Символические ссылки на разделяемые библиотеки: `/usr/lib64/libz.so -> libz.so.1`
- Файлы для средств компоновки: `/usr/lib64/pkgconfig/zlib.pc`
- Документация: страницы руководства `man3`

## 4. Развёртывание изолированного окружения hasher (Задание 4)

- Учётная запись `user` добавлена в группы `hashman`, `user_a`, `user_b`, `rpm` через `/sbin/hasher-useradd`.
- Служба `hasher-privd` активирована в systemd (`systemctl enable --now hasher-privd`).
- Конфигурация `~/.hasher/config`:
  ```bash
  packager="Streltsov Dmitriy <dimasos88@github.com>"
  no_sisyphus_check=all
  ```
- Инициализация chroot выполнена командой `hsh --initroot-only ~/hasher`.
- Разделение прав:
  - Пользователь-сборщик: `builder` (UID 1002, GID 1002), домашний каталог `/usr/src` — выполняет сборку пакетов без привилегий root.
  - Псевдокорневой пользователь: `rooter` (UID 0, GID 0), домашний каталог `/root` — управляет установкой и удалением сборочных зависимостей внутри изолированного chroot.

## 5. Сборка пакетов (Задания 5–7)

### Нулевой пакет `sample-streltsov-1.0-alt1`
- Не содержит файлов (`%files` пуст).
- Собран командой `rpmbuild -ba /usr/src/RPM/SPECS/sample-streltsov.spec`.
- Успешно установлен в chroot: база данных RPM зарегистрировала пакет, однако утилита `which sample-streltsov` подтвердила отсутствие исполняемых бинарных файлов.

### Пакет с функциональностью `streltsov-hello-1.0-alt1`
- Исходный скрипт: `streltsov-hello.sh`, устанавливаемый в `%_bindir/streltsov-hello`.
- Зависимости определены автоматически утилитами `find-requires`: обнаружен шебанг `#!/bin/sh`, сформирована зависимость `Requires: /bin/sh`.
- При запуске выводит:
  ```
  Стрельцов Дмитрий Сергеевич, КТ-22-04, Лабораторная работа № 1
  ```
- Вывод программы полностью совпадает с эталонным файлом `check/expected.txt`.

### Воспроизводимость и сопоставление окружений
- Автоматическая сборка выполнена утилитой `hsh` из файла `streltsov-hello-1.0-alt1.src.rpm`:
  ```bash
  hsh --workdir=~/hasher-rebuild streltsov-hello-1.0-alt1.src.rpm
  ```
- Контрольные суммы SHA-256 исполняемого файла, извлеченного из ручной и автоматической сборок, побайтово идентичны:
  `2c77d5cbacf0169855746a5c07b5c74a3bf973193ed40bd58ac160d2d47df402` (`Hashes match: YES`).
- Число пакетов:
  - Хост-система: 2119 пакетов
  - Изолированное окружение hasher: 182 пакета
  - Разница (только на хосте): 1973 пакета (графическое окружение, офисные пакеты, инструментальные компиляторы и утилиты хоста). Минимализм сборочного chroot гарантирует чистоту сборки и исключает неучтенные неявные зависимости.
