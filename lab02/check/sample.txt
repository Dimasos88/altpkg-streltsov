Сборка и адаптация программных пакетов для отечественных операционных систем
Лабораторная работа № 2: Работа с терминалом и простой проект
Выполнил: Стрельцов Дмитрий Сергеевич, группа КТ-22-04
================================================================================
Строка 01: Текстовый терминал остаётся основным интерфейсом управления системами.
Строка 02: Доступ к оборудованию через последовательный порт и SSH.
Строка 03: Поведение терминала унаследовано от электромеханических устройств.
Строка 04: Часть передаваемых байтов интерпретируется как управляющие символы.
Строка 05: Расширенное управление выводом выполняется управляющими последовательностями.
Строка 06: Для устранения различий в ОС используется база описаний terminfo.
Строка 07: В прикладных программах используется библиотека ncurses.
Строка 08: Инициализация библиотеки выполняется функцией initscr().
Строка 09: Отключение эхо-печати выполняется функцией noecho().
Строка 10: Посимвольный ввод без буферизации строки настраивается функцией cbreak().
Строка 11: Обработка функциональных клавиш активируется функцией keypad().
Строка 12: Создание отдельного окна содержимого: newwin().
Строка 13: Очистка окна: werase().
Строка 14: Вывод строки в окно: waddstr() или mvwaddstr().
Строка 15: Обновление изображения окна на экране: wrefresh().
Строка 16: Ожидание нажатия клавиши: wgetch().
Строка 17: Корректное освобождение ресурсов: delwin() и endwin().
Строка 18: Программа Show размещает файл целиком в оперативной памяти.
Строка 19: Нажатие клавиши пробела прокручивает вывод на страницу вперёд.
Строка 20: Нажатие клавиши 'q' завершает работу программы.
Строка 21: Строки, превышающие ширину окна, автоматически усекаются.
Строка 22: Диагностика ошибок выводится в поток stderr без инициализации ncurses.
Строка 23: При отсутствии аргументов возвращается ненулевой код возврата.
Строка 24: При невозможности открыть файл возвращается ненулевой код возврата.
Строка 25: Проект автоматизируется утилитой make.
Строка 26: Пакет собирается в изолированном сборочном окружении hasher.
Строка 27: Разделение зависимостей на сборочные и эксплуатационные подтверждается тестами.
Строка 28: Отладочный подпакет Show-debuginfo формируется автоматически.
Строка 29: Приёмочная проверка выполняется из свежего клона репозитория Git.
Строка 30: Конец файла.
