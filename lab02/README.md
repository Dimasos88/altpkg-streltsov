# Лабораторная работа № 2. Работа с терминалом и простой проект

**Дисциплина:** Сборка и адаптация программных пакетов для отечественных операционных систем  
**Выполнил:** Стрельцов Дмитрий Сергеевич  
**Группа:** КТ-22-04  
**Операционная система:** ALT Linux 11.1 (p11, x86_64)

---

## 1. Цель работы
Сформировать практические навыки разработки и пакетирования прикладного программного обеспечения с текстовым интерфейсом пользователя в операционной системе «Альт». Исследовать параметры терминала, базу описаний `terminfo` и управляющие последовательности ANSI, разработать программу постраничного просмотра файлов с использованием библиотеки `ncurses`, автоматизировать сборку с помощью утилиты `make`, оформить проект в виде исходного архива и spec-файла с явным разделением сборочных и эксплуатационных зависимостей, собрать пакет в изолированной среде `hasher` и исследовать формирование отладочного подпакета `debuginfo`.

## 3. Разделение сборочных и эксплуатационных зависимостей

В рамках работы экспериментально доказано строгое разделение ролей пакетов библиотеки `ncurses`:

| Пакет | Категория зависимости | Состав файлов | Назначение |
|---|---|---|---|
| `libncurses-devel` | **Сборочная (BuildRequires)** | `/usr/include/curses.h`, `/usr/include/ncurses/`, `/usr/lib64/libncurses.so`, `/usr/lib64/pkgconfig/ncurses.pc` | Необходим компилятору `gcc` и линкеру `ld` во время компиляции программы. Не требуется для запуска! |
| `libncurses6` | **Эксплуатационная (Requires)** | `/lib64/libncurses.so.6.5`, `/lib64/libtinfo.so.6.5` | Динамические разделяемые библиотеки, загружаемые ядром в память при запуске исполняемого файла `Show`. |

При попытке установки пакета `Show` в чистом окружении без `libncurses6` пакетный менеджер RPM выдает фатальную ошибку неудовлетворенных зависимостей. После установки только `libncurses6` программа успешно функционирует без установки `libncurses-devel`.
