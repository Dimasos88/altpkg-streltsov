# Лабораторная работа № 8. Адаптация к окружению при сборке

ALT Workstation 11.1, ветка p11, x86_64. В `keyscan/` находится учебная программа на ncursesw, в `rhasher/` – утилита хеширования. В исходном дереве хранятся configure.ac, Makefile.am, исходники и тесты. Файлы configure, Makefile.in, config.h.in, config.h и Makefile создаются инструментами настройки.

| Параметр | Значение в config.h |
| --- | --- |
| `--enable-keypad --with-margin=2` | `USE_KEYPAD=1`, `WINDOW_MARGIN=2` |
| `--disable-keypad --with-margin=4` | `USE_KEYPAD` не определён, `WINDOW_MARGIN=4` |
| `--without-readline` | `USE_READLINE` не определён |

Make исполняет граф зависимостей и команды сборки. Autoconf генерирует configure, который проверяет компилятор, заголовки и возможность связать тестовую программу с библиотекой. Autoscan предлагает исходные проверки по файлам проекта. Aclocal подбирает макросы, autoheader формирует config.h.in, Automake производит Makefile.in и инфраструктуру тестов. Autoreconf запускает нужные инструменты. CMake и Meson решают схожую задачу конфигурации и генерации, используя собственные форматы проекта и другие бэкенды сборки.

В keyscan обязательна ncursesw. Отсутствие тестовой библиотеки lab08_nonexistent даёт отрицательный результат без остановки. В rhasher обязательна librhash. Readline опциональна. В обычной сборке она нужна только для интерактивного чтения. Поток команд из файла обрабатывается getline до EOF. MD5, SHA-1 и SHA-256 сравниваются со штатными утилитами. Верхний регистр первой буквы включает Base64. Ошибка команды выводится в stderr и не завершает цикл.

Сборка keyscan проверяется в дереве исходников и в отдельном каталоге. Во втором случае make использует путь к исходной директории и локальный config.h. `git-clean-preview` показывает список игнорируемых артефактов, прежде чем отдельная цель `git-clean-generated` их очистит.

[GEAR-репозиторий](https://github.com/Dimasos88/lab08-autotools) содержит исходный профиль и правила экспорта. В spec применены %%autoreconf, %%configure, %%make_build, %%makeinstall_std и секция %%check. Связка %%def_enable и %%subst_enable управляет параметром keypad. В журнале сравниваются две сборки с одним spec-файлом.

`bash check/check-lab08.sh` проверяет проекты и сохраняет протоколы в logs. `LAB08_LOGS` меняет каталог журналов. `LAB08_RPM_EVIDENCE` указывает на журналы RPM и PTY для дополнительной группы проверки. Метаданные pkg-config для librhash подготовлены локально в env/pkgconfig, поскольку использованный ALT RPM разработки не поставляет файл .pc.
